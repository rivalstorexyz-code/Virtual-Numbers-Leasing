# تسعير سلة في لوحة رمزون SMS

- تمت إضافة حقل سعر البيع لكل كود بالريال واختيار مدى/فيزا/أبل باي/STC Pay.
- المعادلة: رسوم العملية = (سعر البيع × النسبة + الرسم الثابت) × 1.15. نسبة الضريبة على رسوم بوابة الدفع فقط.
- أسعار التكلفة من الكتالوج بالدولار تحول إلى ريال بمعامل الإعدادات (3.95 افتراضيًا).
- صافي الربح المتوقع = إجمالي أسعار بيع الأكواد - تكلفة المورد التقديرية - رسوم بوابة الدفع التقديرية.
- لا يوجد ربط بسلة هنا؛ سعر البيع يُدخَل يدويًا. نفترض كل كود طلبًا مستقلاً؛ لو طلب متعدد الأكواد في عملية دفع واحدة، تختلف الرسوم الثابتة.
- الرسوم تقديرية حسب الأرقام التي قدمها مالك المشروع، وليست تحققًا من عقد سلة.
- هذه نسخة مراجعة للاختبار، لا تنشرها قبل اختبار التدفق وحفظ نسخة احتياطية.
- الملفات المعدلة: admin/templates/admin.html فقط؛ عند النشر عبر GitHub تتابع Render على الفرع والإعدادات الصحيحة.
